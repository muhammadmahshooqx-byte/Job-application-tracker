# Job Application Tracker

Job Application Tracker is a full-stack web application built to help job seekers organize and manage their job search by allowing users to add, update, and delete job applications while tracking their status from Applied to Interview, Offer, or Rejected, all through a secure login system powered by JWT authentication. The backend is built using Java and Spring Boot with Spring Security for authentication, Maven for dependency management, and PostgreSQL as the database, while the frontend is built using React and Vite for a fast and responsive user interface. To run the project locally, start the backend by navigating into the application-tracker folder and running mvn spring-boot:run which starts the server on localhost:8080, then start the frontend by navigating into the tracker-frontend folder, running npm install followed by npm run dev, which starts the app on localhost:5173.
